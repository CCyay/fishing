# 偶数流派（平潮体系）设计

> 状态：贴纸全部已实现。这份是对现有牌的**归纳**，不是先有设想再实现的
> —— 设想部分是从牌的效果和数值反推的，改动时以 `stickers.uts` 为准。

## 一、这个流派要做什么

它不跟你抢某一张牌，它**换掉整张牌桌的规则**：十三个数字里七个是奇数，平潮一落地，超过一半的钓点当场消失，而且永久。

之后的牌局是这样的：堆上会积起一大摞谁也钩不动的死牌，只有偶数还能当钓点。**谁先钩中一张偶数，谁就连锅端走那座山。** 于是这个流派做的事只有两件——

1. 让自己还能打出偶数（靠坠子/提系把点数调成偶数）；
2. 手里留着清场的钥匙（拾偶、撒网、淘沙）。

## 二、引擎：0 算偶数

平潮本身只是把奇数压成 0，真正让这套闭环的是另一条规则：

> **0 是偶数，照收**；「没有点数」（空位牌、背面牌）谈不上奇偶，不算。
> —— `fishing.uvue` 的 `hasParity`，拾偶、撒网、庄家估值走的都是它。

这一条把平潮从「搅局」变成了「铺路」：平潮压出来的那一摞 0 点死牌，在拾偶眼里是**从堆底一路连到头的偶数**，一张下去连锅端。没有这条规则，平潮造出的僵局对谁都是死局。

第二条相关规则是续钩：

> 续钩只认 **0 点**，不认空位（`NO_VALUE` 不是 0）。

所以平潮 + 续钩：你打出的每一张奇数落堆即被压成 0，钩不上任何东西，但换来接着再打一张。**把手上一半的废牌变成了出牌节奏**，不封顶，只要还有奇数就能一直接着打。

## 三、平潮的两条刀口

平潮的实现有两个要点，直接决定这个流派怎么玩：

- **压的是候选里的每一个数，不是整张牌**。能算 13/1/2 的幸运 A 挨完刀剩 `0/2` —— 两个奇数都成了 0，去重后跟原来的偶数并排站着。它还活着，只是面窄了，而那个 0 还能喂续钩。
- **这一刀是永久的**。数字直接写死在牌上（`refreshField` 改 `pileValues`），平潮之后被谁钓走了，挨过刀的那几张也变不回原来的数。只有平潮离场**之后**新落堆的奇数才躲得过。

## 四、贴纸清单

| 贴纸 | 档 | 角色 |
|---|---|---|
| 平潮 | 传说 | **引擎**。空位落堆底，堆上奇数永久压成 0 |
| 拾偶 | 史诗 | **清场**。从堆底往右连收偶数，0 算偶数，遇到奇数才停 |
| 撒网 | 传说·成就 | **清场**。选奇数或偶数，堆里所有该类的牌全收 |
| 续钩 | 史诗 | **节奏**。堆里有它时，落堆算 0 点就能接着再打一张 |
| 淘沙 | 稀有 | **搬运**。把所有 0 点牌移到这张牌右侧（堆顶），之后随便哪次钓牌都捎得走 |
| 遮眼 | 稀有 | **补刀**。把它左边 2 张压成 0，不用等平潮 |
| 坠子 / 提系 | 各档 | **调偶**。把自己的关键牌调到偶数，对平潮免疫 |

## 五、典型链条

```
坠子/提系先把牌组的关键牌调成偶数（自己不怕平潮）
        ↓
平潮落堆底 —— 对手手上一半的牌当场作废
        ↓
他打出的奇数全变 0 点，钩不上，只能给堆垫厚
（续钩在场的话，你自己的奇数也能换成出牌节奏）
        ↓
堆底积起一长串 0 点死牌
        ↓
拾偶 / 撒网一张下去，连锅端
```

## 六、这个流派的赌性

**平潮对双方一视同仁**，它是场上规则不是单向压制。所以这套玩起来有两处风险，都得认：

- **那摞金山未必归你**。堆底积的死牌是公共的，你有拾偶，对手也可能有。谁先掏出钥匙谁收摊。
- **没有针对性构筑的牌组，用平潮就是同归于尽**。你的奇数也一起瘫。它真正的价值只有在「我的牌都是偶数、你的不是」时才兑现 —— 这就是为什么坠子/提系是这个流派的必需品而不是可选项。

换句话说：**平潮是一张先手牌，不是一张强牌**。什么时候落地，比落不落地更要紧。

## 七、券的账

引擎和两把钥匙里，平潮占掉传说券 2 张中的 1 张，撒网走成就（不花券），拾偶和续钩各吃 2 张史诗券。剩下的调偶件从普通档的轻坠/小提就能起步。

结论：**这个流派的下限很低、上限很高**。没有平潮时，那几张调偶件本来就是坠子流派的常规牌，不算浪费；一旦摸到平潮（第 9 关解锁，或靠传说随机券），整套立刻成型。

## 八、与其它流派的关系

- **← 坠子流派**：提系压到 0 是两条路的接口，那边的「死牌」在这边是弹药。
- **↔ 控制流派**：抢史诗/传说券。控制要吃满 6 张史诗券（探底/照水/灌铅各 2），偶数要拾偶和续钩各 2 —— **二选一**，这是牌组构筑里最硬的一道取舍。
- **被克**：祛除（撕掉平潮就没戏了，但它得先钩得到）、起底（背面牌没有点数，平潮管不着）。
- **反协同**：混沌流派的背面牌**谈不上奇偶**，拾偶扫到就断。两套凑在一起互相拆台。
