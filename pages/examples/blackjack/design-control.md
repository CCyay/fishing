# 控制流派设计

> 状态：设想已定稿，九张贴纸**已全部实现**。
> 这份文档记的是**为什么**这么设计；具体数值和效果以 `stickers.uts` 为准。

## 一、这个流派要做什么

六条设想，按原话记：

1. 时不时可以看一下对手手牌；
2. 把有危险的牌压回牌组底，或拿到自己手上；
3. 看牌组顶 N 张牌，决定是否压牌底；
4. 适当让对手多抽牌，结合看手牌效果，这样对手就无法触发回合结束补牌；
5. **核心就是让对手乖乖当血包给自己堆牌**；
6. 可以强制对手从牌组／手牌连续出 N 张牌，且强制点数变成 0。

一句话概括：控制流派不比谁钓得多，它比的是**谁还打得出有效牌**。把对手的牌型锁死、把他的钓点废掉，他打出的每一张都在给你垫堆，最后你挑个时间一次收摊。

## 二、引擎：补牌规则

这套能成立，全靠一条规则：

> 回合结束时手牌不足就补齐，**超过不处理，允许超过**。
> —— `fishing.uvue` 的 `tidyPlayerHand` / `tidyDealerHand`，只补不弃。

推论：**只要把对手手牌顶到上限以上，他回合结束就不补牌**。他的牌池被冻结在你已经看过的那几张里，摸不到新东西。于是：

- 「看手牌」从一次性的信息，变成了**持续有效**的情报 —— 反正他换不了牌；
- 「让对手多抽牌」从送资源，变成了**上锁**；
- 两者叠起来，对手就只能打你留给他的废牌。这就是第 4 条和第 5 条的全部机制基础。

注意这条规则对双方对称，所以「双方一起摸牌」的效果实际上是**单向有利**的：多一张牌，对主动方是多一个选择，对被动方是多一张废牌加一层锁。

## 三、贴纸清单

| 贴纸 | 档 | 类别 | 效果 | 对应设想 |
|---|---|---|---|---|
| 窥手 | 普通 | 立即 | 看庄家全部手牌，明示到这一回合结束 | ① |
| 喂食 | 普通 | 立即 | 双方各从自己牌库抽 1 张 | ④ |
| 压舱 | 稀有 | 立即 | 看庄家全部手牌，挑 1 张压到他牌库底 | ①② |
| 摘钩 | 稀有 | 立即 | 看庄家全部手牌，挑 1 张拿到你手上 | ①② |
| 窄口 | 稀有 | 空位·落堆底 | 它在堆里时庄家每回合只补到 4 张 | ④ |
| 探底 | 史诗 | 空位 | 看庄家牌库顶 2 张，逐张决定留还是压到他牌库底 | ③ |
| 照水 | 史诗 | 空位·落堆底 | 它在堆里时庄家手牌一直明示 | ① |
| 灌铅 | 史诗 | 立即 | 双方各抽 2 张，他抽的那 2 张灌了铅：点数永久算 0、贴纸失效 | ④⑥ |
| 闭口 | 传说 | 空位 | 他下一回合从手牌连打 3 张，一律按 0 点正面落堆顶 | ⑤⑥ |

命名沿用钓鱼话：喂食是打窝，窄口是鱼不张嘴，闭口是鱼彻底停口，摘钩是把鱼从钩上取下来，灌铅是坠子灌死让它浮不起来。

### 为什么只有四张是空位类

项目里有一条隐含规律，这九张照着它分：**一次性的操作型效果是立即类**（窥探、换饵、摸底、掏底、对换、洗手都是），**改变场上规则、或强制对手做事的是空位类**（照水、搅局、蒙牌、浑水、闸门都是）。

不把控制牌全做成空位，有两个理由：

- **梯度会断**。现在最低档的空位类是稀有（染色），普通档一张都没有。窥手和喂食是入门件，做成空位就得「垫一层堆 + 放弃这一手钓牌」，普通档付不起这个价。
- **垫堆对控制流派根本不是代价**。空位牌落堆没点数，对手也钩不上 —— 空位牌打得越多，堆里死牌越多，而死牌只有收色、集花这类按花色收的能端走。全改空位等于把控制焊死在花色收割上，反而收窄了。

唯一存疑的是**喂食**：「双方各抽 1 张」对使用者是纯赚，再送一次钓牌机会确实白嫖。它卡在普通档才留了立即类；真要削，最干净的改法是升到稀有再加空位。

### 三张「顶手牌」的梯度

这是骨架，三张各管一段：

- **喂食**（普通）—— 只顶张数。便宜、可重复，用来把锁挂上；
- **灌铅**（史诗）—— 顶张数 **+** 塞两张真废牌。铅是永久的，除非他打掉，否则一直烂在手里。配合窄口（只补到 4 张），他的手牌会越来越接近全是铅；
- **闭口**（传说）—— 反过来把他手牌清空 3 张，全按 0 点倒在**堆顶**。0 点撞不上（他白打），落堆顶（下次谁钩中都带得走，而钩得上的牌在你手里）。这是收摊的信号枪。

前两张把他冻在已知牌里，最后一张决定什么时候收。

## 四、典型链条

```
窥手 / 照水      看清他手上是什么
      ↓
压舱 / 摘钩      把能钩的牌抽走（压到牌库底，或直接拿过来）
      ↓
喂食 / 灌铅      把他手牌顶过上限 —— 从此摸不到新牌
      ↓
（他只能打你留给他的废牌，每打一张都在给你垫堆）
      ↓
灌铅 / 闭口      把那几张压成 0 点垫在堆顶
      ↓
你捏着钩得上的牌，一次收摊
```

## 五、券的账

各档券的总量：普通 13、稀有 6、史诗 6、传说 2（见 `levels.uts` 顶部）。
各档持有上限：普通 4、稀有 3、史诗 2、传说 1（见 `stickers.uts` 的 `RARITIES`）。

- 普通：窥手 ×4 + 喂食 ×4 = 8 张，吃掉 8 券，还剩 5 券留给坠子那类基础件；
- 稀有：压舱 / 摘钩 / 窄口 三种，每种上限 3，而稀有券只有 6 张 —— **必须三选二满编，或者三种都配不满**；
- 史诗：探底 / 照水 / 灌铅 各 2 张正好吃满 6 券 —— 代价是放弃平潮那条线；
- 传说：闭口占掉 2 张传说券里的 1 张。

全力投控制能凑出约 21 张贴纸牌，占 52 张牌组的四成。**这是个配得齐的流派**，同时稀有档的三选二和史诗档的全投入都是真实取舍，不会变成无脑堆料。

## 六、解锁分配

插进现有关卡，不动其它贴纸：

| 关卡 | 加入 |
|---|---|
| 第 1 关 | 窥手 |
| 第 2 关 | 喂食 |
| 第 3 关 | 压舱 |
| 第 4 关 | 摘钩 |
| 第 5 关 | 窄口（从第 7 关挪来） |
| 第 7 关 | 灌铅（补窄口挪走的位置） |
| 第 9 关 | 闭口 |

普通档的两张放在最前面，是因为它们是这个流派的入门件；没有它们，前几关根本玩不出控制的感觉。

## 七、实现要点

- **窥手的「明示到回合结束」**：用现有的 `dealerHandOpen`，照水走的也是同一个开关（`showDealerHand` computed），不用新机制。
- **喂食 / 灌铅的「抽牌」**：从各自的牌库游标往后取，`playerCursor` / `dealerCursor` 各推一格，直接 push 进手牌。不走 `tidy*Hand`，那是补牌的路。
- **灌铅的铅**：给抽上来的那 2 张写 `forced = 0`，并且**必须一并清掉 `stickerKey`** —— 不然幸运、福星那几张还能从 0 派生出 13/1/2，铅就白灌了。
- **闭口的 0 点强制**：给那一方记一笔「接下来 3 张按 0 点落堆」的欠账，跟 `maskLeft`（蒙牌）、`playerForced`（浑水）是同一类标记，接在 `commitPlay` 落堆那一段。和浑水的区别：浑水是背面沉堆底，闭口是**正面 0 点落堆顶**。
- **压舱 / 摘钩的选牌**：复用 `PICK_THEIRS`（摸底、掏底、对换走的那套），只是挑完之后的去向不同。

## 八、与其它流派的关系

- **浑水属于混沌流派**，不归控制。它逼对手背面连打 3 张沉堆底，那几张谁也拿不到 —— 是拖延和搅乱，不是养血包。闭口才是控制版本的「强制连打」。
- **平潮（传说）** 是偶数流的核心，跟控制抢史诗／传说的位置。控制要吃满史诗券就得放弃它。
- **窄口、照水、探底** 落堆底或占堆位，天然跟收割类（拾偶、收色、撒网）互补：它们把堆养厚，收割类负责端走。
