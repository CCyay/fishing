# 坠子流派（点数流）设计

> 状态：贴纸全部已实现。这份是对现有牌的**归纳**，不是先有设想再实现的
> —— 设想部分是从牌的效果和数值反推的，改动时以 `stickers.uts` 为准。

## 一、这个流派要做什么

它不直接抢牌，它改的是「这张牌算几点」。两条支线，方向正好相反：

- **拢点数**（坠子系、提系、暗桩）—— 把满盘散着的十三个数字挤到少数几个上。
  牌组里一半的牌都算 7 点的时候，你随便打两张就能自己钩自己。
- **拓钓面**（幸运、福星、游动、跳钩、放线、长线、倒影）—— 让一张牌同时算好几个数。
  一张福星牌能算五个数，钩上堆里任何一张的概率就高得多。

两条都在回答同一个问题：**怎么让「打出的牌钩得上堆里的牌」这件事从撞运气变成算术。**

## 二、引擎：牌落堆不坍缩

> 一张能算 13/1/2 的牌落进堆里，这三个数**同时**是它的钓点。
> —— `cards.uts` 的 `valuesOf` / `shareValue`，判撞找的是「候选有交集」。

这条规则把拓钓面那一支的价值抬高了一大截，也给它装了个反噬：

- **进攻面**：你打出的福星牌有五个数，堆里任何一张沾上其中一个就钩得走；
- **防守面**：它落堆之后**同样**在堆里占五个数，对手接上任何一个都能把它连同后面那摞带走。

所以拓钓面不是无脑强化，是**把牌变成一把双刃**：钩得多，也更容易被钩。派生系贴纸越堆越多，你的牌在堆里活得越短。这正是它跟拢点数那一支的分界——拢点数是把钓点攥在自己手里（我知道我下一张也是 7），拓钓面是把钓面铺开赌先手。

## 三、贴纸清单

### 拢点数：定值系

| 贴纸 | 档 | 效果 |
|---|---|---|
| 轻坠 / 小坠 | 普通 | 点数 +1 / +2 |
| 中坠 / 重坠 | 稀有 | +3 / +4 |
| 沉坠 / 巨坠 | 史诗 | +5 / +6 |
| 轻提 / 小提 | 普通 | −1 / −2，最低 0 |
| 中提 / 重提 | 稀有 | −3 / −4，最低 0 |
| 沉提 / 巨提 | 史诗 | −5 / −6，最低 0 |
| 暗桩 | 史诗 | 点数一律按 11 算，打出时落到堆底 |

加减各排到 6，是因为要把 4/5/6/7 全调到 10，需要的正是 +6/+5/+4/+3 —— **大数才是凑套的瓶颈**，稀有度按稀缺性排而不是按单张强度排。

两头各有一个出口：

- **往上推过 10 成「大数」**。11 及以上是大数区间，这条路是下面第七节的大数支流。
- **往下压到 0 成「死数」**。0 当不了钓点，这条路通向偶数流派（0 算偶数、续钩认 0 点）。

### 拓钓面：派生系

| 贴纸 | 档 | 加出来的候选 |
|---|---|---|
| 幸运 | 隐藏 | ±1 |
| 游动 | 稀有 | 顺位 −1 |
| 跳钩 | 稀有 | 顺位 +2 |
| 倒影 | 成就 | 按 22 减去它算 |
| 福星 | 成就 | ±1、±2 |
| 放线 | 史诗 | +2、+3 |
| 长线 | 传说 | +3、+4、+5 |

全部按顺位转圈（K 往上是 A，A 往下是 K），所以大牌小牌一视同仁。一张牌只贴得下一张贴纸，这几套永远不会叠在同一张牌上。

### 配套件

| 淘沙 | 稀有 | 把堆里所有 0 点牌移到这张牌右侧 —— 提系压出来的死牌这才变得成分 |
| 遮眼 | 稀有 | 把它左边 2 张的点数压成 0 —— 废掉对手现成的钓点 |
| 祛除 | 稀有 | 从堆里挑 1 张撕掉贴纸 —— 对面点数流的解药 |

## 四、典型链条

**拢点数打法**（同号流）：
```
坠子 / 提系把牌组大量点数调到同一个数
        ↓
连投（稀有）从牌库连打 3 张 —— 这三张会互相钩
        ↓
第 2 张钩第 1 张，收走；第 3 张接着打
```
连投在点数发散的牌组里是纯送分，在同号牌组里是自带牌桌的三连击。这一对是全牌表里配合最紧的组合之一。

**拓钓面打法**：
```
福星 / 长线堆在关键牌上 → 一张牌钩得上堆里大多数数字
        ↓
堆越厚它越值钱（钩中堆底能连锅端）
        ↓
但它落堆后同样是对手的肥肉，所以要么当回合钩走，要么别打出去
```

## 五、券的账

坠子系横跨普通（4 张）、稀有（4 张）、史诗（4 张）三档，是**唯一一条在每个档位都有件的支线**，也因此是唯一能靠券量配满的流派：普通 13 券配 4 种 ×4 张就吃掉 16 张牌位的一多半。

派生系相反，集中在成就和史诗/传说：幸运靠随机券抽、福星和倒影靠成就、放线史诗、长线传说。**拓钓面配不齐是常态**，它更像是给某几张关键牌镀层，不是铺满牌组的路子。

## 六、大数支流

> 11 及以上是大数，10 及以下是小数。分界线在 `fishing.uvue` 的 `BIG_LINE`。

挑 11 当线，是因为 **J 从不落堆**——打出就通吃走了，所以 11 是牌堆里天然的空缺。普通牌组根本凑不出 11，要够到它得靠暗桩、归深或者坠子往上推。**这就是「私有钓点」的由来**：不是你占了某个数，是那个数本来没人到得了。

这条支流做三件事：**在别人够不着的地方建钓点**、**把对手的牌推出他自己的射程**、**把小数的收益压到最低**。

### ① 建钓点

| 贴纸 | 档 | 效果 |
|---|---|---|
| 暗桩 | 史诗 | 点数一律按 11 算，落堆底 —— 唯一真正私有的钓点 |
| **归深** | 史诗 | 永续：**还可以视为 11 点**，不管本来是几 |
| 坠子系 ×6 | 普通→史诗 | +1…+6，把牌推过 10 |

暗桩是**覆盖**（原点数没了），归深是**追加**（原点数还在）——这个区别决定了用法，见下面「还没解的」第一条。

### ② 推出射程（放大系）

| 贴纸 | 档 | 类别 | 效果 |
|---|---|---|---|
| **涨水** | 普通 | 空位 | 全堆有点数的牌各 +1 |
| **托底** | 稀有 | 空位 | 左边 2 张各 +2 |
| **抽底** | 稀有 | 立即 | 左边 1 张变 0，自己加上它的点数 |
| **涨潮** | 史诗 | 空位 | 左边 1 张 +10 |
| **掏空** | 史诗 | 立即 | 左边 2 张变 0，自己加上其中较大的那个 |

**类别按机制定，不按档位**：改别人点数的自己站开（空位、不判撞），从别人身上抽点数的自己必须在场（立即）。不加空位的话，推完的结果可能正好撞上自己的点数，当场把刚推走的牌又钩回来——同一张牌的效果取决于有没有撞上，玩家没法预判。

**三种改点数的方式，安全性不同**：

| 方式 | 贴纸 | 会不会撞出重复 |
|---|---|---|
| 全体同增 | 涨水 | 不会。原本各不相同的，加完还是各不相同 |
| 归零 | 抽底、掏空 | 不会。0 不参与匹配（`shareValue` 里 `if (a[i] <= 0) continue`） |
| 精准挪位 | 托底、涨潮 | 会，但**可控**——推谁、推成几点都是玩家看着牌面定的 |

这也是「倒灌」（全场推小数 +10）被砍掉的原因：推全场时玩家逐张控制不了，`1/2/3` 还会被推回对手射程、撞成一对反倒送对手一个肥钩点。**不可控的重复才是真问题。**

统一规则：全部跳过 0 点牌和没有点数的牌，死牌保持死着。

### ③ 压制小数

| 贴纸 | 档 | 管什么 |
|---|---|---|
| 闸门 | 史诗 | **能走多远**：钩牌遇到比钩中数字大的牌就停，11 以上不算坎 |
| **深水** | 传说 | **能不能收**：钩中 10 以内的数只带走钩中那张和自己 |
| 齐顶 | 史诗 | 打出时算堆里最大点数 —— 回收变现 |

### 核心闭环

```
暗桩落堆底，点数纯 11 —— 对手够不到
      ↓
闸门让他的小数走不远，深水让他钩中也只捞两张
放大系把他打下来的牌一张张推出射程
      ↓
他钩不动，只能往上垫。堆越来越厚，厚的全是他的牌
      ↓
带归深的大数牌靠 11 钩中堆底的暗桩
      ↓
收割从堆底一路走到堆顶，中间他垫的全归你
```

### 归深解决了什么

大数原本有个致命矛盾：**造大数只能靠坠子，而坠子是定值加成，永远只有一个候选**。在牌落堆不坍缩的规则下多候选才是优势，大数流派却主动把自己的钓面砍到最窄；而且两张牌要想互相钩，得精确凑成同一个数（巨坠史诗上限 2 张，正好只够凑一对，多一张都没有）。

归深一张牌把这两个问题一起解了：**贴了它的牌都可以视为 11**，不管本来是几。K 算 `{13, 11}`，3 算 `{3, 11}`，两张八竿子打不着的牌就此钩得到一起——凑对不用算术了，贴上就是同伙。

选 11 是因为 **J 从不落堆**（打出就通吃走了），普通牌组根本凑不出 11。所以这不是「占了一个数」，是**那个数本来没人到得了**，归深是进场的唯一入口（暗桩是另一个）。

它不要求牌先进大数区间，所以严格说归深是**独立的 11 网络**，跟坠子推上去的大数是两套东西，只是常搭在一起用。

### 深水和闸门的分工

两张都在压小数，但压法不同，叠起来才完整：

- **闸门**管「**能走多远**」——钩中的数往右走，遇到比它大的牌就停，**但 11 以上的大数不算坎**。
- **深水**管「**能不能收**」——钩中 10 以内的数，整段作废，只带走钩中那张和自己。

闸门这条要留意它的实际算法，很反直觉：

```uts
if (worth > line && worth <= BIG_LINE) { break }   // BIG_LINE = 10
```

**大数不是墙，大数是畅通证。** `line >= 11` 时，「比它大」和「不超过 10」永远不可能同时成立——所以拿大数钩进来一路收到底，不需要任何特例照顾。反过来拿小数钩进来，路上随便一张稍大的小牌就是坎，走两步就断。

对手拿小数打进来，闸门让他走不远，深水让他就算钩中也只捞两张。**他唯一的出路是打 11 以上的数**——J（通吃，端整堆）、Q、K，或者他自己也带了坠子。这正是「让对手只有出 JQK 才有收益」。

### 还没解的

- **归深是追加不是覆盖，所以埋底会被反杀**。`valueOptions` 里它是 `alts.push(11)`——原点数还在。K+归深 算 `{13, 11}`，对手一张普通 K 就钩得走它，然后把你养的整堆连锅端。**所以归深牌只能当收尾，埋底必须用暗桩**（点数被覆盖成纯 11，对手真的够不到）。这个分工是使用要点，不是 bug：多一个候选换来钩面，也换来破绽，这是它该付的代价。
- **对收割类仍然裸奔**。收色、集花认花色，撒网、拾偶认奇偶，拖网的范围判定 `% 13` 之后把 19 当 6 算——大数只对「钩数字」这一种收法免疫，对另外五种毫无办法。这是这条支流的固有弱点，留着。
- **闸门和深水是场上规则，对双方一视同仁**。天生大数只有 Q、K 八张，坠子系全买满 18 张，加起来正好半副牌——另一半你照样会摸到，打出去同样走不远、同样只收两张。**半吊子大数流派会自己卡死自己**，换钩（压至多 3 张手牌到牌库底）是配套的过牌器。
- **抽底和掏空的即时收益是 0**。自己涨到 20 出头之后，堆里基本不会有那个数，判撞钩不中。它们是布局牌，价值在「对手少了钓点、你多了一张安全的大牌」，别指望当场换分。
- **庄家不会用这套**。闸门、深水、归深、放大系都没进任何关卡的 `dealerStickerKinds`，闸门的 `stickerGain` 还返回 0（空位牌 gain 为 0 就给 −50 分，几乎不会打出去）。这套压制目前是单向的，是内容缺口不是设计缺口。
- **庄家的账已经补上了**。`pileThreat` 原本只算「有钓点的牌」，会以为大数牌和 0 点牌摆在堆里绝对安全；现在加了 `carried`，从堆底往右推着算「被左边的钓点捎走」的半份风险。不补这段的话，庄家正是在送分最多的时候最放心。

## 七、与其它流派的关系

- **→ 偶数流派**：提系压到 0 是两条路的接口。压出来的 0 点牌在偶数流派里不是废牌（0 算偶数，拾偶收得走；续钩认 0 点，能换一次出牌）。
- **→ 控制流派**：灌铅给对手的牌写死 `forced = 0` 并清掉贴纸 —— 那是用点数机制做控制，原理同源。
- **被克**：祛除（撕贴纸）、平潮（奇数压 0，把你精心调好的奇数全废掉）。点数流最怕的是自己的算术被人改写。
- **大数支流被克**：收色、集花、撒网、拾偶 —— 全是不看点数的收法，大数在它们面前没有任何优势。想防这些得另外配花色或奇偶的对策。
- **大数支流克制**：所有靠小数吃饭的打法。闸门加深水在场时，10 以内的数钩进来既走不远也收不动，而你的大数钩一路畅通。
